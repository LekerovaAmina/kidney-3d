# 🫘 Почка — интерактивный 3D-атлас

Учебный сайт по биологии про почку человека: 3D-модель, которую можно вращать и разрезать,
анимированная схема нефрона, образование мочи, гормоны, кровоснабжение, болезни, история, факты, квиз
и QR-код для макета.

## Что внутри

| Раздел | Что умеет |
|---|---|
| **3D-модель** | вращение, масштаб, разрез, клик по любой части → описание, анимация «Построить почку» (слой за слоем), кровоток (артерия/вена) и движение мочи |
| **Где находится** | схема тела: позвонки Th12–L3, рёбра, печень, надпочечники, мочеточники |
| **Цифры** | анимированные счётчики |
| **Нефрон** | анимированная SVG-схема: фильтрат течёт по канальцу, видно обмен веществ; клик по отделу |
| **Моча** | 3 этапа, 180 л → 1,5 л, сравнение первичной и конечной мочи |
| **Функции, РААС, гормоны, путь крови** | карточки и схемы |
| **Болезни, история, советы, факты** | вкладки, таймлайн, переворачивающиеся карточки |
| **Квиз** | 10 вопросов с объяснениями |
| **QR-код** | генерируется для адреса сайта, можно скачать PNG или распечатать |

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install      # один раз — установить зависимости
npm run dev      # открыть http://localhost:5173
npm run build    # собрать готовый сайт в папку dist/
```

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub и загрузите проект:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/kidney-3d.git
   git branch -M main
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. Через 1–2 минуты сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/kidney-3d/`
   (файл `.github/workflows/deploy.yml` уже всё настраивает).
4. Откройте опубликованный сайт → раздел **QR-код** → **Скачать PNG** — этот QR и клеим на макет.

Подойдут и Netlify / Vercel: команда сборки `npm run build`, папка `dist`.

## Структура

```
src/
  kidney/
    geometry.js        — математика 3D-модели (форма почки, пирамиды, сосуды, чашечки)
    KidneyModel.jsx    — 3D-сцена: материалы, разрез, анимации, частицы кровотока
    KidneyExplorer.jsx — панель управления и описание частей
  data/
    parts.js           — тексты для частей 3D-модели и шаги «Построения»
    content.js         — ВЕСЬ остальной текст сайта (правьте здесь)
  sections/            — разделы страницы
  components/          — меню, счётчики, анимация появления
  styles.css           — оформление
```

## Технологии

React 19 · Vite · three.js · @react-three/fiber · @react-three/drei · qrcode.react
